# Research: 会话消息交互改进

## Decisions

- **待办定位**：现有待办面板按待办文本查找消息后已取得消息 ID，但 `focusMessage` 目前只查助手消息节点。给用户回合绑定 ID 并扩展定位函数即可满足本轮需求，无须改变 `TodoItem` 或 IPC。
- **高亮安全**：在已渲染的用户气泡内匹配文本并以文本节点/元素处理；不得将消息正文拼入 HTML。
- **用户消息收藏**：复用现有 `favoriteId`、`toggleFavorite` 与收藏模型；右键菜单只需将用户消息 ID 传给现有应用回调。
- **Agent 选择**：复用 `agentOptions`、`settings:set` 与 `sessions:setAgent`。选择器明确将内置选项标为“API”。先保存默认值，再更新空闲会话；若第二步失败，尝试恢复旧默认值并让界面反映最终状态。
- **模型菜单来源入口**：在 CLI 模型菜单新增独立“切换 API/CLI…”项并弹出 API/已配置 CLI 列表；调用与左侧选择器相同的切换逻辑，不替换 CLI 默认、配置模型、候选列表或自定义模型项。
- **工具详情**：继续使用现有工具卡与回合折叠容器；移除参数/结果的重复标题，保留真实内容、状态、Diff 和审批操作；长内容放入固定高度滚动区域。
- **相关文件**：以现有消息提及解析、`store.state.diffs` 修改记录和当前打开标签为三个来源，统一路径并去重；不增加 IPC 查询或持久化索引。
- **Escape 关闭**：委托已有标签关闭函数，复用脏文件确认；文件标签激活时响应，不抢占模态对话框的 Escape。
- **当前配置标记**：设置页按 `defaultAgent` 标记 API 或具体 CLI 配置为新会话默认值；只展示配置名称，不访问密钥。
- **Token 估算**：不增加 tokenizer 依赖；用可预测的文本启发式估算可见消息与工具调用内容，主标签显示 `≈`，tooltip 说明估算范围并排除隐藏上下文与真实计费口径。
- **待办跳转时延**：目标消息在目标会话加载后立即定位，不增加额外计时器；跨会话时只等待必要的会话数据加载。
- **Web 定位浮条**：只从页面移除 `.loc-bar` 浮动开关及其专属样式；保留 Alt+Q 状态切换、悬停高亮、定位操作条和修改记录面板。
- **Agent 名称展示**：助手消息头显示各消息记录的 Agent 名称；右侧会话上下文不重复呈现该名称。
- **会话上下文与侧栏**：移除用户指定的冗余上下文条目；把快速教程按钮放到设置按钮之后的 rail 底部。布局调整不新增状态、IPC 或持久化。

## Alternatives Considered

- 为待办增加持久化 `sourceMessageId`：本轮既有待办按文本定位，增加字段会触及冻结契约和后端存储，超出确认的前端泳道范围。
- 新增原子化 Agent IPC：会扩大契约与后端改动；通过前端顺序更新、失败补偿及运行态守卫即可满足本轮验收。
