# Feature Specification: 会话消息交互改进

**Feature Branch**: `006-chat-interactions`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "修复待办跳转定位与高亮；支持右键收藏用户消息；在模型入口左侧加入 API/CLI Agent 切换并在 CLI 模型菜单提供来源弹出；精简工具结果、展示去重后的相关文件、支持 Escape 关闭文件、标注当前配置并显示对话 Token 估算；移除待办卡头部按钮与 Web 预览浮动定位栏。"

## Clarifications

### Session 2026-10-22

- Q: 待办跳转应如何定位和提示目标？ → A: 按来源用户消息定位，滚动到消息，并短暂高亮整条气泡及命中的待办文本。
- Q: 右键收藏用户消息应保存什么？ → A: 收藏整条用户消息快照，并保留回到来源会话和消息的定位信息。
- Q: API/CLI Agent 切换影响哪些设置？ → A: 切换器列出 API 和每个已配置 CLI；切换更新当前空闲会话和新会话默认值，模型显示跟随 Agent，共享权限设置不变，运行中禁用切换。
- Q: 相关文件清单由哪些来源组成？ → A: 合并消息提及、修改记录和已打开标签，并对重复路径去重。
- Q: 工具调用内容应如何精简？ → A: 保留参数、结果、状态、Diff 与审批操作，只隐藏冗余的“参数/结果”标题；详情区可折叠且固定高度、超出可滚动。
- Q: 所有会话如何显示 Token 数？ → A: 对话内容统一显示 Token 数估算，并明确标为约值。
- Q: CLI 模型菜单如何提供 API/CLI 来源选择？ → A: 新增独立的“切换 API/CLI…”菜单项，弹出 API 与各已配置 CLI 的选择；保留现有模型选项。
- Q: 移除 Web 预览定位栏时保留哪些能力？ → A: 只移除浮动 `loc-bar`；保留 Alt+Q、定位操作条和修改记录功能。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 从待办准确跳回对话 (Priority: P1)

用户点击待办来源后，界面回到包含该待办文本的用户消息，滚动到目标消息，并短暂突出整条消息气泡及待办文字。

**Why this priority**: 待办若不能把用户带回原始上下文，任务记录就难以验证或继续处理。

**Independent Test**: 在包含待办文字的用户消息创建待办，点击待办并确认目标消息进入可视区域、整条气泡与匹配文字均出现短暂高亮。

**Acceptance Scenarios**:

1. **Given** 待办文字来自一条用户消息，**When** 用户点击该待办且目标会话内容已加载，**Then** 界面按该消息的 ID 立即滚动至该消息，不增加人为等待或长时间滚动动画。
2. **Given** 目标消息包含待办文字，**When** 定位完成，**Then** 整条用户消息气泡与命中的待办文字都短暂高亮。
3. **Given** 没有用户消息可由待办内容匹配，**When** 用户点击待办，**Then** 不发生未处理错误或错误跳转，待办仍保留。

---

### User Story 2 - 右键收藏用户消息 (Priority: P1)

用户在任务会话中右键一条用户消息，可以将整条消息加入收藏；收藏保留会话与消息来源，便于之后跳回原文。

**Why this priority**: 用户需要将自己的问题或上下文作为可复用记录，而不只收藏助手回答。

**Independent Test**: 对一条用户消息右键并选择“加入收藏”，确认收藏完整消息快照及来源，并从收藏入口返回原消息。

**Acceptance Scenarios**:

1. **Given** 用户右键一条用户消息且没有选中文本，**When** 菜单打开，**Then** 菜单提供“加入收藏”。
2. **Given** 用户选择“加入收藏”，**When** 收藏保存完成，**Then** 收藏包含整条消息内容及其会话/消息来源。
3. **Given** 用户消息已收藏，**When** 用户从收藏入口打开它，**Then** 界面返回原会话并定位到原消息，原始聊天记录保持不变。

---

### User Story 3 - 在输入区切换 Agent 来源 (Priority: P1)

用户可在模型入口左侧选择 API 或任一已配置 CLI，也可从 CLI 模型菜单中的独立“切换 API/CLI…”菜单项打开来源列表。选择会更新当前空闲会话和新会话默认 Agent；模型显示随 Agent 更新，而权限仍由共享设置控制。助手消息头显示该消息对应的 Agent 名称。

**Why this priority**: API 与 CLI 共存时，用户需要在发起任务前明确选择执行来源，并让后续新会话沿用选择。

**Independent Test**: 分别切换 API 和两个已配置 CLI，确认当前空闲会话与新会话默认值同步、模型信息正确，且共享权限值不变。

**Acceptance Scenarios**:

1. **Given** 存在 API 和若干已配置 CLI，**When** 用户打开 Agent 切换器，**Then** 可选项包含 API 与每个已配置 CLI。
2. **Given** 当前会话空闲，**When** 用户切换 Agent，**Then** 当前会话 Agent 与新会话默认 Agent 均更新，模型入口显示与所选 Agent 对应的模型信息。
3. **Given** 用户切换 Agent，**When** 操作完成，**Then** 共享权限设置保持不变。
4. **Given** 会话正在运行，**When** 用户查看来源选择入口，**Then** 左侧选择器与 CLI 模型菜单中的来源入口都不可用于切换，当前会话及默认 Agent 不发生变化。
5. **Given** 用户创建新会话，**When** 会话初始化，**Then** 新会话继承最近保存的默认 Agent。
6. **Given** CLI 模型菜单已打开，**When** 用户选择“切换 API/CLI…”，**Then** 菜单弹出 API 与所有已配置 CLI 的来源选择，且现有模型选项仍保留。
7. **Given** 助手消息由 API 或 CLI 生成，**When** 用户查看消息头，**Then** 显示对应 Agent 名称；右侧上下文栏不重复显示 Agent 名称。

---

### User Story 4 - 精简浏览工具调用结果 (Priority: P1)

用户展开某轮工具调用详情时，可以在不丢失操作内容的前提下浏览参数与结果；冗余的小标题不再占据空间，长内容保留在可滚动的固定高度区域内。

**Why this priority**: 工具输出可能很长，过多嵌套标题和无限增长的面板会挤压对话上下文。

**Independent Test**: 展开包含多张工具卡的助手回合，确认参数、结果、状态、Diff 与审批操作仍可访问；长文本在固定高度区域内滚动，标题保持可折叠。

**Acceptance Scenarios**:

1. **Given** 助手回合包含工具调用，**When** 用户展开工具详情，**Then** 操作名、参数和结果内容均保留，且冗余的“参数/结果”标题不显示。
2. **Given** 工具结果超过详情区域高度，**When** 用户查看结果，**Then** 内容在固定高度区域内滚动，不无限撑开聊天页面。
3. **Given** 工具调用处于待审批或已产生 Diff，**When** 用户查看详情，**Then** 状态、Diff 及批准/拒绝操作仍可用。

---

### User Story 5 - 从会话上下文打开相关文件 (Priority: P1)

用户可在会话上下文栏的文件子栏目查看本轮对话提及、修改记录与已打开标签中的文件；相同路径只出现一次，点击条目打开文件，按 Escape 关闭当前文件标签。

**Why this priority**: 在对话、修改记录和打开文件间集中导航，能减少查找文件与返回任务上下文的操作。

**Independent Test**: 准备同时出现在多个来源中的文件，确认清单仅显示一个条目；打开后按 Escape 关闭标签，未保存时沿用现有确认流程。

**Acceptance Scenarios**:

1. **Given** 文件出现在消息提及、修改记录或已打开标签中的一个或多个来源，**When** 用户查看文件子栏目，**Then** 所有来源合并且相同路径只显示一次。
2. **Given** 文件出现在相关文件清单，**When** 用户点击该文件，**Then** 对应文件在文件查看区域打开。
3. **Given** 文件标签处于激活状态，**When** 用户按 Escape，**Then** 当前标签按现有关闭规则关闭；若有未保存修改，用户可取消关闭并保持文件打开。

---

### User Story 6 - 识别当前配置并查看对话 Token 估算 (Priority: P2)

设置界面清楚标注新会话当前默认使用的 API 或 CLI 配置；聊天输入区页脚对 API 与 CLI 会话统一展示对话 Token 数估算，并明确标为约值。

**Why this priority**: 用户可快速确认新会话将使用的配置，并比较不同会话的对话规模，而不会把估算误认为模型账单或真实上下文用量。

**Independent Test**: 分别将默认 Agent 设为 API 与已配置 CLI，确认正确配置带有“使用中”标记；检查空会话显示约 0，消息变化后估算随之更新且始终标明约值。

**Acceptance Scenarios**:

1. **Given** 新会话默认 Agent 为 API 或某个 CLI，**When** 用户打开设置界面，**Then** 对应配置被标注为正在使用，且不显示任何密钥内容。
2. **Given** 当前会话属于任一 Agent 来源，**When** 用户查看输入区页脚，**Then** 都能看到明确带“约”标记的对话 Token 数；空会话显示 0。
3. **Given** 当前会话消息新增或更新，**When** 聊天内容刷新，**Then** 对话 Token 估算随当前可见消息内容更新。

---

### User Story 7 - 简化项目待办卡片操作 (Priority: P2)

用户通过项目待办标题展开或收起卡片；卡片头部不再显示固定和关闭按钮。

**Why this priority**: 移除重复的头部操作，保持待办卡片控制方式简单一致。

**Independent Test**: 打开项目待办卡片，确认固定与关闭按钮不存在，点击标题仍可展开和收起卡片。

**Acceptance Scenarios**:

1. **Given** 项目待办卡片显示，**When** 用户查看卡片头部，**Then** 不出现固定或关闭按钮。
2. **Given** 项目待办卡片已展开，**When** 用户点击标题，**Then** 卡片收起；再次点击标题可重新展开。

---

### User Story 8 - 移除 Web 预览浮动定位栏 (Priority: P2)

Web 预览不再显示浮动的 UI 定位开关栏，但用户仍可通过 Alt+Q 开关 UI 定位，并继续使用定位操作条和修改记录面板。

**Why this priority**: 常驻浮动栏占用预览空间；保留快捷键和记录面板可继续支持开发定位工作流。

**Independent Test**: 打开 Web 预览确认 `body > div.loc-bar` 不存在；按 Alt+Q 后仍能启用定位并访问操作条与修改记录。

**Acceptance Scenarios**:

1. **Given** Web 预览已加载，**When** 页面初始化完成，**Then** 页面不挂载 `body > div.loc-bar`。
2. **Given** Web 预览已加载，**When** 用户按 Alt+Q，**Then** UI 定位仍可开关，悬停高亮、定位操作条与修改记录仍正常工作。

### User Story 9 - 简化会话上下文与侧栏入口 (Priority: P2)

右侧会话上下文不重复显示助手消息头已经展示的 Agent 名称，并移除用户指定的多余上下文条目；快速教程入口位于侧栏底部、设置入口之后。

**Why this priority**: 减少重复信息，并将低频教程入口放到侧栏底部，不干扰主要视图导航。

**Independent Test**: 检查助手消息头的 Agent 名称与右侧上下文栏，确认名称只保留在消息头；确认指定上下文项不可见，快速教程按钮位于设置按钮之后。

**Acceptance Scenarios**:

1. **Given** 会话上下文栏显示，**When** 用户查看 Agent 信息，**Then** 上下文栏不重复显示 Agent 名称，且用户指定的额外条目不出现。
2. **Given** 侧栏已渲染，**When** 用户查看 rail 底部，**Then** 快速教程入口位于设置入口之后且仍可用。

## Edge Cases

- 待办文字匹配多条用户消息时，沿用当前历史顺序中的第一条匹配消息；同一消息内重复出现时只高亮首个精确匹配区间。
- 没有用户消息可匹配待办文字时，不抛出未处理异常、不误定位到其他消息，待办保持不变。
- 收藏已存在时，不产生重复收藏。
- 尚未配置 CLI 时，切换器仍可选择 API。
- 任一写入失败时尽力恢复已成功写入的一侧；若补偿失败，选择器须反映实际持久化状态并提示错误，不得显示为同步成功。
- 会话运行状态在切换操作期间改变时，不允许对运行中的会话写入 Agent。
- 同一路径以不同来源或斜杠形式出现时，相关文件清单仍只保留一个条目；没有文件来源时显示空状态。
- Escape 仅关闭激活文件标签；若关闭确认被取消，文件和编辑状态保持不变。
- Token 数是可见对话内容的估算值，不包含隐藏提示或协议开销；空会话的估算值为 0。
- 项目待办标题仍是展开/收起入口；移除固定/关闭按钮后不得遗留不可见的置顶状态。
- 移除浮动定位栏后，Alt+Q 必须仍能切换定位状态；操作条与修改记录面板不随浮动栏一起移除。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 每条用户消息 MUST 可通过稳定的消息 ID 被聊天视图定位。
- **FR-002**: 当现有待办文本匹配规则解析出来源用户消息时，点击待办 MUST 按该消息 ID 滚动到目标，并将整条消息气泡高亮约 1.4 秒。
- **FR-003**: 若待办文本可在来源消息中匹配，系统 MUST 同时将命中片段高亮约 1.4 秒；高亮不得改变或破坏原始消息内容。
- **FR-004**: 右键用户消息 MUST 提供“加入收藏”，无须先选中文字。
- **FR-005**: 用户消息收藏 MUST 保存完整消息快照及会话/消息来源；对原聊天记录的修改 MUST 为零。
- **FR-006**: Agent 切换器 MUST 位于模型入口左侧，沿用输入区现有控件样式，不得与模型/权限控件重叠，并展示 API 与所有已配置 CLI。
- **FR-007**: Agent 变更 MUST 同步到当前空闲会话（若存在）与新会话默认值。
- **FR-008**: 模型入口 MUST 显示与当前 Agent 对应的模型信息；Agent 切换 MUST NOT 改变共享权限设置。
- **FR-009**: 会话运行中，Agent 切换 MUST 禁用；运行状态变化不得造成部分更新。
- **FR-010**: Agent 切换后的新会话 MUST 使用已保存的默认 Agent。
- **FR-011**: 工具调用详情 MUST 保留操作名、参数、结果、状态、Diff 与审批操作，同时隐藏冗余的“参数/结果”标题。
- **FR-012**: 工具调用长内容 MUST 位于可折叠、固定高度且可滚动的详情区域；内容不得因长度而无限撑开聊天页面。
- **FR-013**: 设置界面 MUST 标注新会话当前默认使用的 API 或 CLI 配置；标记不得泄露密钥。
- **FR-014**: 会话上下文栏 MUST 合并消息提及、文件修改记录与已打开标签中的相关文件，并按路径去重。
- **FR-015**: 点击相关文件条目 MUST 打开对应文件；按 Escape MUST 关闭激活文件标签，并保留现有未保存修改确认语义。
- **FR-016**: 输入区页脚 MUST 对 API 与 CLI 会话显示当前对话 Token 数估算，空会话显示 0。
- **FR-017**: Token 数估算 MUST 明确标注为约值，并随当前会话可见消息内容更新；不得呈现为真实模型用量。
- **FR-018**: 项目待办卡片头部 MUST 不显示固定或关闭按钮；标题仍可展开/收起卡片。
- **FR-019**: CLI 模型菜单 MUST 提供独立的“切换 API/CLI…”入口，弹出 API 与所有已配置 CLI 的来源选择；不得替换或删除现有模型选择项。
- **FR-020**: Web 预览 MUST 不挂载 `body > div.loc-bar` 浮动栏；Alt+Q 定位开关、定位操作条和修改记录功能 MUST 保持可用。
- **FR-021**: 助手消息头 MUST 显示生成该消息的 Agent 名称。
- **FR-022**: 右侧会话上下文栏 MUST 不重复显示助手消息头展示的 Agent 名称。
- **FR-023**: 用户指定的多余上下文条目 MUST 不再显示。
- **FR-024**: 快速教程入口 MUST 位于侧栏底部、设置入口之后，且继续可用。

### Key Entities

- **用户消息来源**：会话 ID、消息 ID，以及用于匹配待办的消息文本。
- **收藏快照**：完整消息文本、来源会话、来源消息和收藏时间；快照与原聊天消息相互独立。
- **Agent 选择**：API（内置 Agent）或一个已配置 CLI 的引用。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 对仍可按现有规则匹配到来源的待办，点击后 100% 定位到对应消息；整条消息与匹配文本高亮约 1.4 秒后自动结束；未匹配待办不产生错误跳转。
- **SC-002**: 右键任一用户消息均可完成收藏；收藏快照和来源信息完整率为 100%，原消息内容无变化。
- **SC-003**: Agent 切换后，当前空闲会话与新会话默认值一致率为 100%，模型标签与 Agent 配置一致率为 100%。
- **SC-004**: 会话运行期间成功切换 Agent 的次数为 0；切换前后共享权限值保持一致。
- **SC-005**: 每个已确认的工具调用参数、结果、状态、Diff 与审批操作均可访问；长结果在固定高度的滚动区域内查看。
- **SC-006**: 相关文件清单中来自三个来源的每个唯一路径均可打开且只出现一次；Escape 关闭激活标签时不丢弃未确认的修改。
- **SC-007**: API 或 CLI 默认配置与设置界面“使用中”标记完全一致，标记内容中不包含密钥。
- **SC-008**: API 与 CLI 的空会话都显示约 0；新增或更新对话消息后，约 Token 数更新且可见近似标记。
- **SC-009**: 待办跳转在目标会话内容加载后立即开始定位，不引入额外定时等待或长时间滚动动画。
- **SC-010**: 项目待办卡片中固定/关闭按钮数为 0，标题展开与收起均可用。
- **SC-011**: CLI 模型菜单中来源选择入口可见，选择 API 或已配置 CLI 时沿用现有同步/权限规则，且原模型选项均仍可用。
- **SC-012**: Web 预览中 `body > div.loc-bar` 数为 0；Alt+Q 仍能开关定位，操作条与修改记录可访问。
- **SC-013**: API/CLI 助手消息头显示正确 Agent 名称，右侧上下文栏不重复显示该名称。
- **SC-014**: 用户指定的上下文条目不可见；快速教程入口位于设置入口之后的 rail 底部且可打开。

## Assumptions

- API 对应现有内置 Agent；CLI 选项仅来自已保存的 CLI 配置。
- 待办与收藏沿用现有来源记录；本功能不新增项目级待办持久化模型。
- 配置“使用中”标记指向新会话默认 Agent；会话级 Agent 仍由会话自身状态显示。
- Token 估算只代表可见对话文本规模，不等同于 API/CLI 实际计费或完整上下文窗口用量。
- 项目级待办与全项目清理/性能审计另立规格和跨泳道任务，不属于本功能。
- API 保存项目界面及收藏/项目待办完整 CRUD 另行拆分规格；本功能只调整待办卡片头部与待办跳转体验。
- 高亮效果为短暂提示，结束后恢复原有视觉状态。
