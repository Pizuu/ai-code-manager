# Quickstart: 会话消息交互改进

## 自动验证

从仓库根目录运行：

```powershell
npm run test
npx eslint .
npx tsc --noEmit
npm run build
```

无需新增依赖或配置。

## 手动验收

1. 打开一个任务会话，右键用户消息中的选中文本并加入待办；点击待办，确认滚动到对应用户气泡，整条气泡和命中片段约 1.4 秒后恢复。再检查无法匹配到用户消息的待办不会报错或误跳转，且仍保留。
2. 对一条未选中文字的用户消息打开右键菜单并加入收藏；在收藏列表中打开该收藏，确认回到同一会话和原消息，原消息未变化。
3. 在设置中配置 API 与至少两个 CLI；在空闲会话中逐一切换，确认选择器位于模型入口左侧、与现有输入区控件样式一致且不重叠，当前会话和新会话默认 Agent 同步、模型信息跟随、权限模式不变。
4. 启动会话运行后确认 Agent 选择器不可用；运行完成后恢复可用。
