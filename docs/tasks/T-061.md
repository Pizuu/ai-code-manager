## 目标

从 Web 预览移除常驻浮动 `loc-bar`，保留 Alt+Q 定位开关、操作条和修改记录面板；同时完成 Agent 名称去重、指定上下文项移除和快速教程入口移至 rail 底部，并运行整批前端最终验证。

## 允许修改的路径

- `src/frontend/web/locator.ts`
- `src/frontend/web/locator.css`
- `src/frontend/views/session-view.ts`
- `src/frontend/views/shell.ts`

## 依赖契约

- 不涉及 IPC 契约；Web 预览定位器仅用于开发预览，不进入打包产物。

## 验收标准

- [ ] 页面不再挂载 `body > div.loc-bar`；移除其专属 CSS。
- [ ] Alt+Q 仍可开关 UI 定位；悬停高亮、定位操作条和修改记录面板仍可用。
- [ ] 右侧上下文不重复显示 Agent 名称；用户指定的冗余上下文条目不再显示。
- [ ] 快速教程入口位于设置入口之后的 rail 最底部，点击仍可打开菜单。
- [ ] `npm run web` 手动验收通过。
- [ ] 最终运行 `npm run test`、`npx eslint .`、`npx tsc --noEmit`、`npm run build`、`scripts/verify.sh` 与 `scripts/check-lane.sh`；仅修复本泳道引入的问题。

## 不做什么

- 不移除 Alt+Q 快捷键、操作条、记录面板或修改记录数据。
- 不修改打包用渲染层 `src/frontend/styles.css`。
- 不更改消息头 Agent 名称渲染（由 T-056 验收）。

## 给 agent 的提示

- `.loc-bar` 是可见入口；`setOn` 与快捷键仍需工作。移除 DOM 后清理只服务于该按钮的事件与样式，同时确保状态切换不引用已销毁元素。
