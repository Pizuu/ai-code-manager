## 目标

精简工具调用详情的重复标题并限制长输出区域高度；操作内容和审批流程不得被隐藏或改变。

## 允许修改的路径

- `src/frontend/views/tool-card.ts`
- `src/frontend/views/chat.ts`
- `src/frontend/styles.css`

## 依赖契约

- 不涉及 IPC 契约；复用现有工具调用、Diff 与审批数据。

## 验收标准

- [ ] 冗余的“参数/结果”小标题不显示，操作名、参数与结果内容仍可访问。
- [ ] 长输出在固定高度区域内滚动，不无限撑开聊天页面；外层详情仍可折叠。
- [ ] 工具状态、Diff 和批准/拒绝操作仍然可用。
- [ ] 这是 DOM/CSS 展示调整，按宪法五不新增单测；完成 quickstart 对应手动验收。
- [ ] `scripts/check-lane.sh` 全绿。

## 不做什么

- 不改工具执行、审批、Diff 数据或 IPC。
- 不修改项目级清理、Token 估算或设置页逻辑。

## 给 agent 的提示

- 保留每张工具卡的操作名、状态与参数/结果正文；只移除重复层级标题。
- 固定高度和滚动仅作用于详情正文，不遮挡工具卡头部与审批按钮。
