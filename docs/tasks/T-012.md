## 目标

在 windows-latest 上执行 `npm run dist`，验证安装版与便携版可启动，并加入 CI。

## 允许修改的路径

严格等于 `.agents/lanes.conf` 中本泳道的 glob：`.github/* scripts/* .agents/* .gitignore .editorconfig .vscode/* .specify/*（不含 .specify/memory/*）`。

## 依赖契约

- contracts/ipc.ts v1、contracts/fixtures/

## 验收标准

- [ ] CI windows 作业产出 NSIS 与 portable 两个 exe
- [ ] `scripts/check-lane.sh infra` 全绿
- [ ] `scripts/verify.sh` 全绿

## 不做什么

- 不修改契约与其他泳道文件；如需新增 devDependency（如 playwright），在 PR 的「需要 coordinator 处理」中提出，由 coordinator 在 `int/*` 分支修改 package.json。
