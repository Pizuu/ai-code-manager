## 给 agent 的提示

- git < 2.38 不支持 `merge-tree --write-tree` 时返回 `unknown`，不要谎报「无冲突」。
- 引用监听用轮询而非 `fs.watch`：refs 可能落在 `packed-refs` 或分散在 worktree 里。
