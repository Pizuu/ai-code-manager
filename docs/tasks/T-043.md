把「为什么这么做」写进仓库：ADR 0010 记录终端模式与「全部允许（免审批）」的取舍，宪法升到 1.3.0（原则 九 增加显式豁免、原则 十一 补终端工作目录）。

- `.specify/memory/*`

## 验收标准

- [x] ADR 0010 含背景（orca 对照表）、决策 5 条、备选 4 条、后果与接受的风险
- [x] 宪法 1.3.0：原则 九 允许「全部允许」模式豁免询问；原则 十一 明确终端工作目录恒为项目根
- [x] 决策目录索引补 ADR 0010

## 不做什么

- 不在 ADR 里写实现细节（细节在任务卡与代码注释）

## 给 agent 的提示

- ADR 0010 的「后果」段必须写明：终端内执行的命令不经过审批卡片（负责人明确授权的形态），且**项目根沙箱不豁免**。
- ADR 0010 备选 1（真 PTY）被否的理由是 ADR 0001「运行时不引入第三方依赖」，将来要上真 PTY 需先修订 ADR 0001。
