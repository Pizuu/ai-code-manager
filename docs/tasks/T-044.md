## 目标

泳道守卫此前只在 `dev` / `main` 上触发，而 `dev` 分支在本地与 origin 都不存在 —— 合入集成分支的 PR 从不触发泳道检查。现改为以 `.agents/config.sh` 的 `INTEGRATION_BRANCH` 为唯一权威。

## 允许修改的路径

- `.github/**`
- `scripts/**`
- `.agents/**`

## 依赖契约

- 无

## 验收标准

- [x] `lane-guard.yml` 的触发分支列表含当前集成分支（`manus`）与仍存在于 origin 的历史名
- [x] `scripts/check-branch-config.sh` 校验工作流分支列表与 `.agents/config.sh` 一致，不一致即失败
- [x] `scripts/verify.sh` 与 `ci.yml` 都跑该检查
- [x] 「只有集成分支能合入 main」的守卫改用 `config.sh` 读到的分支名

## 不做什么

- 不改 `.agents/lanes.conf` 的泳道划分
- 不改 `scripts/check-lane.sh` 的判定逻辑

## 给 agent 的提示

- 触发列表里的历史名若在 origin 已不存在会被判为漂移并让 CI 失败 —— 集成分支再改名时要同步清理。
- 本机没有 bash 时可用 Git Bash 跑：`& "C:\Program Files\Git\bin\bash.exe" scripts/check-branch-config.sh`。
