## 目标

在模型入口左侧增加 API/CLI 来源选择器，更新当前空闲会话和新会话默认 Agent，并保持模型与共享权限显示正确；确认助手消息头展示该消息对应的 Agent 名称。

## 允许修改的路径

- `src/frontend/*`
- `tests/*/frontend/*`

## 依赖契约

- 无新增契约；复用现有 `agentOptions`、`settings:set`、`sessions:setAgent`。

## 验收标准

- [ ] 单测覆盖 API 与 CLI 选择、当前会话/默认值同步、权限不变、运行中禁用、补偿成功以及补偿失败后的实际状态呈现，并验证助手消息头 Agent 名称。
- [ ] 选择器位置与样式符合 FR-006，不与模型/权限控件重叠；模型标签跟随所选 Agent。
- [ ] 助手消息头展示对应 Agent 名称；右侧上下文去重由后续 T-061 验收。
- [ ] CLI 模型菜单含独立“切换 API/CLI…”入口，弹出 API 与已配置 CLI 选择并沿用同一切换流程；原有 CLI 默认、配置模型、候选与自定义模型选项均保留。
- [ ] `npm run test`、`npx eslint .`、`npx tsc --noEmit`、`npm run build`、`scripts/verify.sh` 全绿。
- [ ] `scripts/check-lane.sh` 全绿；quickstart 手动验收通过。

## 不做什么

- 不修改 IPC 契约或后端权限；不变更共享权限设置。
- 不执行项目级清理、性能重构或 API 保存项目 UI 工作。

## 给 agent 的提示

- 内置选项应明确显示为“API”，各 CLI 使用其配置名称；运行中不可切换。
- 任一步写入失败时尽力补偿；若补偿失败，选择器反映实际持久化状态并提示错误，不得显示为同步成功。
