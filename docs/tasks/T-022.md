## 完成记录（2026-10-20）

- `src/backend/agent-cli/opencode-serve.ts`：启动 / 附着 `opencode serve`（随机端口、随机密码、basic auth、退出杀进程树），SSE 事件映射到 `parseOpencodeLine`，`permission.asked` → `ApprovalRequest`，逐条回复 once / reject；停止时先拒绝全部待批再 abort。**未接入** run 模式。
- 17 条单测（注入 fetch / spawn / 定时器的假 HTTP/SSE 服务器，夹具取自 1.19.3 真实响应）；全量 203/203。
- 真实 opencode 1.19.3 + 本地假模型实测：询问模式、自动批准编辑模式、待批中停止三种情形均正确。
- 结论写入 ADR 0006 修订；后续需 contracts 卡扩展 `ApprovalRequest` 的权限类型（webfetch / doom_loop / task）后再接入。
