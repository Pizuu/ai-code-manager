## 目标

允许用户在未选中文字时右键整条用户消息并收藏；收藏保留完整快照及来源，原聊天记录不变。

## 允许修改的路径

- `src/frontend/*`
- `tests/*/frontend/*`

## 依赖契约

- 无新增契约；复用现有 `favoriteId`、收藏存储与消息来源格式。

## 验收标准

- [ ] 单测覆盖用户消息右键收藏入口、完整快照/来源和重复收藏。
- [ ] 既有助手消息收藏行为保持不变；`npm run test`、`scripts/verify.sh` 全绿。
- [ ] `scripts/check-lane.sh` 全绿。
- [ ] 手动从收藏入口返回同一会话中的原用户消息。

## 不做什么

- 不编辑收藏快照，不修改原聊天记录，不改 `contracts/`、`src/backend/` 或项目级待办。
- 不进行全项目重构或模拟数据清理。

## 给 agent 的提示

- 右键用户消息无须先选中文字；收藏时保存完整消息内容而非选区。
- 使用 T-054 已加入的消息 ID，并保留助手消息现有收藏路径。
