## 目标

渲染层长出提醒呈现：P0 审批弹窗栈（完整内容、命令原文不截断；查看跳转切会话并定位高亮审批卡；弹窗内直批 / 直拒复用既有审批通道；正看着该审批时不弹窗；已解决自动撤下）与待办收件箱。收件箱入口定版（负责人 2026-10-21 定位）：shell 的 rail 底部组、主题切换按钮上方新增收件箱按钮（即 rail 第 7 个 a.ri 区域），带未消解角标；点击打开收件箱弹层，含「待处理 / 历史」两页签——待处理汇总未消解事项（按级别 / 时间排列、稍后与已读的本地状态），历史按 FR-515 沉淀已决审批流水（结果 / 时间 / 会话 / 内容摘要，来自 approval-resolved 事件，重启后从会话持久化记录重建，只读不可改判）。弹窗被关掉但未处理的审批留在待处理页签、计数不变。P1–P3 的事项生成在 T-049 接入本容器。
