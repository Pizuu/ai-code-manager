## 目标

点击项目待办后，能稳定定位到解析出的用户消息并短暂高亮整条气泡和匹配文本；文本无法匹配时不误跳转。

## 允许修改的路径

- `src/frontend/*`
- `tests/*/frontend/*`

## 依赖契约

- 无新增契约；沿用现有会话待办与消息 ID。

## 验收标准

- [ ] 单测覆盖用户消息定位、重复/无匹配、原文不被破坏及约 1.4 秒高亮规则。
- [ ] `npm run test`、`scripts/verify.sh` 全绿。
- [ ] `scripts/check-lane.sh` 全绿。
- [ ] 手动点击待办后，目标会话内容就绪即开始定位，不增加人为定时等待或长时间滚动动画；正确用户气泡短暂高亮，无匹配时无报错、无错误跳转。

## 不做什么

- 不新增 todo 的持久化消息 ID，不改 `contracts/` 或 `src/backend/`。
- 不调整项目级待办模型或进行全项目清理。

## 给 agent 的提示

- 复用当前待办文本匹配并取得消息 ID 的流程；修复用户回合缺少可定位 ID 的问题。
- 高亮处理不可把消息正文拼入 HTML；同一条消息内重复文本只高亮首个匹配。
