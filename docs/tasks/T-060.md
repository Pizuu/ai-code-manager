## 目标

设置页标记新会话默认使用的 API/CLI 配置；所有 Agent 来源的会话在输入区页脚显示明确为约值的对话 Token 估算。

## 允许修改的路径

- `src/frontend/lib/token-estimate.ts`
- `src/frontend/views/chat.ts`
- `src/frontend/views/settings-dialog.ts`
- `tests/unit/frontend/lib/token-estimate.test.ts`

## 依赖契约

- 不涉及 IPC 契约；复用现有 `defaultAgent`、会话消息与工具调用状态。

## 验收标准

- [ ] 确定性单测覆盖空会话、ASCII、中文/Unicode、消息集合与工具调用文本的估算。
- [ ] 页脚对 API/CLI 会话均显示带 `≈` 的估算数；空会话显示约 0，消息变化后更新，并提示估算范围。
- [ ] 设置页按 `defaultAgent` 标记新会话正在使用的 API 或具体 CLI 配置；不渲染或泄露密钥。
- [ ] 复用现有 `.ft-tokens` 与 `.chip` 样式，不修改 `src/frontend/styles.css`。
- [ ] `scripts/check-lane.sh` 全绿。

## 不做什么

- 不引入第三方 tokenizer，不新增后端用量采集或计费逻辑。
- 不声称估算值等于供应商实际用量、上下文窗口占用或计费 Token。

## 给 agent 的提示

- 用可预测的轻量文本启发式，不增加周期轮询；避免每次渲染都重复扫描未变化的整段历史。
- “使用中”表示新会话默认配置，不代表当前会话级 Agent 覆盖。
