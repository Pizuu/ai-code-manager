## 目标

设置对话框新增「提醒」分区：按 P0–P3 四级分别开关系统通知与提醒声音、设置稍后时长，读写 v1.13 的 Settings 提醒偏好；默认值按 FR-512（系统通知 P0/P1 开、P2/P3 关，声音关，稍后 10 分钟）。分区文案明示：关掉系统通知不影响应用内呈现，未消解计数（尤其 P0）没有任何开关可以关掉。

## 允许修改的路径

严格等于 `.agents/lanes.conf` 中本泳道的 glob：`src/frontend/* tests/*/frontend/*`。

## 依赖契约

- contracts/ipc.ts v1.13（T-046）的提醒偏好字段与默认值口径
- 既有 settings:get / settings:set 通道

## 验收标准

- [ ] 四级 × 两开关 + 稍后时长可改、可保存、重开设置读回一致
- [ ] 与 T-047 / T-048 联调口径一致：设置改动对已在途事项不追溯，只影响新事项（在卡内注明此口径）
- [ ] `scripts/verify.sh` 全绿；`scripts/check-lane.sh frontend` 全绿

## 不做什么

- 不实现通知发送与弹窗呈现本身。
- 本卡与 T-048、T-049 同为 frontend 泳道，必须串行派发，不并行开分支。

## 给 agent 的提示

设置对话框是标签页式配置卡片（第十七批定版形态），提醒分区按同一形态接入，别另起对话框。偏好字段缺失（老设置文件）时按 FR-512 默认值呈现，不许呈现为全关。
