## 目标

主进程托管任务会话的终端进程（管道式，非真 PTY），并把「全部允许（免审批）」权限模式在内置 agent / ACP / serve / run 四条通道上统一落地。

## 允许修改的路径

- `src/backend/**`

## 依赖契约

- `contracts/ipc.ts`（v1.6）

## 验收标准

- [x] 测试：`tests/unit/backend/terminal/terminal-manager.test.ts`、`tests/integration/backend/ipc/handlers-terminal.test.ts` 通过
- [x] 测试：权限模式四分支的既有单测补齐 `allow-all` 用例
- [x] `scripts/verify.sh` 全绿
- [x] `scripts/check-lane.sh` 全绿

## 不做什么

- 不引入 `node-pty` / `xterm.js`（ADR 0001 / ADR 0010 备选 1）
- 不做终端 resize、不做全屏 TUI 支持
- 不给终端进程开项目根以外的路径（工作目录恒为项目根，宪法 十一）

## 给 agent 的提示

- 终端输出经 `agent:event` 的 `terminal-data` / `terminal-exit` 回流；主进程退出时 `closeAll()` 结束全部终端。
- `terminal:open` 必须先确认会话存在（`sessions.get`），避免为不存在的会话启动进程。
- 权限模式：`decide()` / `acpAutoDecision()` / `serveRules()` / `opencodePermission()` + `needsTurnApproval()` 四处都要认 `'allow-all'`；`external_directory` 仍 deny。
