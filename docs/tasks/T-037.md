## 目标

契约升到 v1.6，纯增量地给出：任务会话「终端模式」的三个 invoke 通道与两个事件变体，以及第 4 种权限模式「全部允许（免审批）」。

## 不做什么

- 不改既有字段与既有枚举值的语义（宪法 二：冻结后只许加可选字段）
- 不引入 `terminal:resize`（等真 PTY，ADR 0010 备选 1）

## 给 agent 的提示

- `PermissionMode` 加 `'allow-all'` 属**新增枚举值**（纯增量），既有三个值语义不变。
- 终端通道只收 `sessionId` / `kind` / `restart`——**不允许**渲染进程传路径或命令原文（宪法 十一）。
- preload 白名单（`src/backend/preload.cts`）与 Web 预览白名单（`contracts/web-dev.ts`）都有编译期穷举检查，漏一条即编译失败。
