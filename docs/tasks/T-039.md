## 目标

任务会话中列出现「对话 / 终端」分段切换：对话模式是原有对话视图，终端模式显示项目根下的终端面板；每个会话记住自己的模式。

## 允许修改的路径

- `src/frontend/**`

## 依赖契约

- `contracts/ipc.ts`（v1.6）

## 验收标准

- [x] 测试：`tests/unit/frontend/lib/ansi.test.ts` 覆盖 ANSI 解析（纯函数）
- [x] `scripts/verify.sh` 全绿
- [x] `scripts/check-lane.sh` 全绿
- [x] Web 预览冒烟通过（`node scripts/web-smoke.ts`，新增 terminal:open 通道检查）

## 不做什么

- 不做上下分屏同时显示两种视图（本期只做切换；Orca 的切换器也不分屏）
- 不引入 xterm.js（ADR 0010 备选 1）
- 不动对话视图既有行为（`showChat()` 改为切回对话模式）

## 给 agent 的提示

- 中列布局由 `.mid`（列）改为 `.mid` → `.modebar` + `.midbody`（行）：CSS 里 `.mid.split` 的选择器要同步改成 `.midbody.split`。
- 模式按会话 ID 存 `localStorage`（`acm.sessionModes`），切换会话时恢复各自模式。
- 终端输出走 `store` 的 `terminals` topic（按会话 ID 索引），切回会话时输出仍在。
- 终端输入是行式：回车提交一行并补 `\r\n`；子进程不回显，界面自行回显。
