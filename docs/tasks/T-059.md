## 目标

在会话上下文栏汇总去重后的相关文件并支持 Escape 关闭当前文件；移除项目待办卡头部的固定和关闭按钮，保留标题折叠。

## 允许修改的路径

- `src/frontend/lib/session-files.ts`
- `src/frontend/views/session-view.ts`
- `tests/unit/frontend/lib/session-files.test.ts`

## 依赖契约

- 不涉及 IPC 契约；复用现有消息提及、修改记录、打开标签及文件关闭流程。

## 验收标准

- [ ] 单元测试覆盖三个文件来源合并、路径去重、空清单和 Escape 关闭判定边界。
- [ ] 相关文件子栏目包含消息提及、修改记录与已打开标签；重复路径只出现一次，点击条目打开对应文件。
- [ ] Escape 关闭当前激活文件标签；未保存确认取消时文件与编辑状态保持不变。
- [ ] 项目待办头部不再显示固定/关闭按钮，标题仍可展开/收起；移除按钮后待办内容保留。
- [ ] `scripts/check-lane.sh` 全绿；按 quickstart 手动验收文件打开、Escape 和待办折叠。

## 不做什么

- 不新增项目级待办或文件索引持久化模型。
- 不修改 `src/frontend/styles.css`；复用现有上下文栏和待办样式，避免与 T-058 的共享样式文件冲突。
- 不重构收藏 CRUD 或项目级存储。

## 给 agent 的提示

- 文件来源限定为消息提及、修改记录和已打开标签，并按路径规范化去重。
- Escape 必须服从未保存修改的既有确认/取消行为；不要关闭其他模态对话框。
